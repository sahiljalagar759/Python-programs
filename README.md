# Python-programs
This repository contains various Python programs created for the Software Tools and Technologies Lab (BUEL456A). 

### Contents:
Program 1: Implementation of the Selection Sort algorithm, which includes time complexity analysis and graph plotting for a varying number of elements.  

Program 2: Implementation of the Quick Sort algorithm, which includes time complexity analysis and graph plotting for a varying number of elements.  

Program 3: Implementation of the Merge Sort algorithm, which includes time complexity analysis and graph plotting for a varying number of elements.  

Program 11: A multi-thread application that uses separate threads to continuously generate a random number, calculate its square, and calculate its cube.  

Program 12: Implementation of a Stack data structure using arrays, featuring push, pop, and display operations with overflow and underflow checks.
